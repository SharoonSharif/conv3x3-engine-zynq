# Testbenches

Self-checking, bit-exact against `tb/vectors/` (generated by
`golden/gen_vectors.py`, 160x120 scene).

* `tb_engine.v` — two frames through `conv3x3_engine`: frame 1 with the reset
  Sobel kernels, then a full 19-write AXI4-Lite kernel swap (cycle count is
  printed), then frame 2 with the swapped kernel. Checks every pixel and the
  TLAST count.
* `tb_sobel_fixed.v` — one frame through `sobel_fixed`.

Both apply **random AXI4-Stream backpressure** (LFSR-driven `m_axis_tready`,
about 80% ready) and random input gaps (about 75% valid).

Run **from the repository root** (the testbenches read `tb/vectors/...`
relative to the working directory).

## Vivado xsim (Windows)

Put `<Vivado>\bin` on PATH, then:

    tb\run_xsim.bat

Logs go to `tb/logs/`. Each run must end in `TB PASS`.

## Icarus Verilog

    iverilog -g2012 -o eng.vvp rtl/conv3x3_engine.v tb/tb_engine.v
    vvp eng.vvp +CFG=tb/vectors/cfg_sobel.hex     +EXP2=tb/vectors/exp_sobel.hex
    vvp eng.vvp +CFG=tb/vectors/cfg_scharr.hex    +EXP2=tb/vectors/exp_scharr.hex
    vvp eng.vvp +CFG=tb/vectors/cfg_gaussian.hex  +EXP2=tb/vectors/exp_gaussian.hex
    vvp eng.vvp +CFG=tb/vectors/cfg_laplacian.hex +EXP2=tb/vectors/exp_laplacian.hex
    iverilog -g2012 -o sob.vvp rtl/sobel_fixed.v tb/tb_sobel_fixed.v && vvp sob.vvp

## Recorded results (`tb/logs/`, xsim 2026.1, 2026-09-29)

| Run | Result |
|---|---|
| engine, frame 2 = Sobel / Scharr / Gaussian / Laplacian | 0 mismatches / 19,200 px on both frames, TLAST 240/240, **TB PASS** (x4) |
| kernel swap | 76 clock cycles for 19 AXI4-Lite writes |
| sobel_fixed | 0 mismatches / 19,200 px, TLAST 120/120, **TB PASS** |

**Coverage limit:** simulation is at W = 160, H = 120 only. The W = 1920
configuration used for the second set of implementation reports has **not**
been simulated.
